# Knomee Advisor — Demo

A recreation of the Knomee Advisor prototype (from Figma) as a React +
TypeScript + Vite app, with a **Prospects → Convert → Clients** flow and a
Figma-style **commenting overlay** for reviewers, deployed on GitHub Pages.

[Figma reference »](https://www.figma.com/design/8HhKtgP7kuKaaC7IvWWjhO/Knomee---Demo--2026--NEW?node-id=19003-21027)

## What's in it

- **My Prospects** — top bar, tabs, Top Line Metrics, Actionable Insights, and
  the tier-grouped prospects table (KQ / Intent / Clarity / Receptivity).
- **Convert flow** — each prospect's `⋯` menu → *Convert to client* → a
  confirmation modal → the prospect lands in **My Clients** as a freshly
  onboarded client (highlighted "new" row + a toast).
- **My Clients** — the converted book of business: households, sentiment,
  status, grouped by engagement tier.
- **Responsive** — tables drop columns progressively at each breakpoint
  (mirroring the converting-flow prototype), so nothing overflows.
- **Commenting overlay** — a persistent, Figma-style review layer that wraps
  the whole prototype. Hidden by default; press **F2** to toggle it (F12 is
  left for devtools), then drop numbered pins and leave/resolve threads.
  Comments persist via Firestore, namespaced by `PROJECT_ID`.

## How it's structured & deployed

GitHub Pages serves the repository's files **statically** (no build step on
GitHub's side), so:

- `index.html` — the static commenting overlay (site root). It iframes the app
  and is toggled with **F2**.
- `app/` — the **pre-built** React prototype (relative base), regenerated by
  `npm run build`. The overlay iframes `./app/app.html`.
- `.nojekyll` — lets Pages serve the `app/assets/` folder verbatim.

> After changing anything under `src/`, run `npm run build` to refresh `app/`
> and commit the result, since Pages serves the built files directly.

Make sure GitHub Pages is set to serve this branch's root.

## Getting started

```bash
npm install
npm run dev      # React app on http://localhost:5173 (app only)
npm run build    # type-check + rebuild app/ (what Pages serves)
```

To exercise the overlay locally, serve the repo root statically (e.g.
`python3 -m http.server`) and open `index.html`.

```

  index.css              # aliases the tokens + all styling
  reviewBridge.ts        # forwards F2 + reports height to the overlay
  components/icons.tsx    # inline SVG icons
  screens/               # pages reached from the burger menu
    SegmentationScreen.tsx + segmentation.css
    ClientExperienceScreen.tsx + client-experience.css
  data/{prospects,insights,clients,segmentation,experience}.ts
```

## Design tokens

Colour, type and space live in `src/tokens/`, synced from the **Knomee Design
System** project on claude.ai/design — which was itself built from this repo and
reconciled the two token files that had drifted apart (`src/index.css` and
`wireframes/tokens/colors.css`; the shipped values won). `index.css` aliases its
long-standing names (`--plum`, `--line`, …) onto those tokens, so the value for
any colour now exists in exactly one place. `src/screens/client-experience.css`
is the design system's mobile layer, kept beside the screen it styles.

See `src/tokens/README.md` for what is and isn't imported, and how to re-sync.

## Client Experience (mobile)

Burger menu → **Mobile → Client Experience** shows the client-facing app inside
an iPhone frame (390 × 844): the **My Adventures** home screen, with a three-
destination tab bar — Adventures · Knomee · Financial ID. The way back to the
adviser side lives in the phone's own burger menu ("Advisor Experience"), so
the mobile demo is driven entirely from inside the device.
